# รูปแบบการทำงานที่ผู้ใช้ต้องการ

## ลงมือเองตรง ๆ ไม่ใช้ workflow

ผู้ใช้ระบุชัดว่า **ไม่ต้องการให้ delegate งานไปที่ workflow / sub-agent** เพราะช้า
กฎนี้ override steering ระดับ global ที่บอกให้ delegate งาน implementation ทุกครั้ง

ให้ทำงานเองในเซสชันนี้โดยตรง:

- อ่านโค้ดที่เกี่ยวข้องด้วยเครื่องมืออ่านไฟล์/ค้นหาเอง
- แก้ไฟล์เอง
- รัน type-check / lint / build / test เอง
- รายงานผลตรง ๆ ในแชท

ข้อยกเว้นเดียว: ใช้ workflow เมื่อผู้ใช้ **สั่งเอง** เช่น "รัน workflow X" หรือ "ให้ agent ทำ"

## ยังต้องทำตามเสมอ

- อ่านโค้ดจริงก่อนแก้ ห้ามเดา API หรือ props
- verify ก่อนบอกว่าเสร็จ (ดู §16 ของ `AGENTS.md`)
- ทำตามกฎสไตล์ใน `AGENTS.md` ทุกข้อ
- แก้เฉพาะสิ่งที่โจทย์ต้องการ
